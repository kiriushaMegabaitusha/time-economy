# Plan: Implement Database Editing Features

## Overview

The Time Economy application is a cybernetic time-based labor market for small communities (5-10 people). It uses SQLite with SQLAlchemy ORM and provides three interfaces:
1. **Web UI** - FastAPI with Jinja2 templates and Tailwind CSS
2. **TUI** - Textual-based rich terminal interface
3. **CLI** - Typer-based command-line interface
4. **Simple CLI** - Plain-text menu interface for low-tech environments

## Current Database Structure

### Models (app/models.py)
- **Member**: id, name, email, phone, bio, status, joined_at, initial_credit
- **Skill**: id, member_id, name, category, description
- **SkillWant**: id, member_id, name, description
- **Transaction**: id, from_member_id, to_member_id, hours, service_description, status, created_at, completed_at, notes
- **Need**: id, member_id, title, description, hours_estimated, status, created_at, fulfilled_at
- **GovernanceLog**: id, member_id, decision_type, title, description, vote_for, vote_against, status, created_at
