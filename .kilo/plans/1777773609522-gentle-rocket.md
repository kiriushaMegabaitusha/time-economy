# Fix TUI - Plan

## Confirmed Issues

### 1. `top_skills` wrong type (CRASH on dashboard line 105)
**File**: `app/services.py:75-78`
`services.get_dashboard_stats()` returns SQLAlchemy `Row` objects, but `dashboard.watch_stats()` line 105 accesses `stats["top_skills"][0]['name']` — which fails because Row objects don't support `['name']` dict-style access (only `.name` attribute access).
**Fix**: Convert to list of dicts.

### 2. No database table initialization before TUI
**File**: `app/tui/app.py`
The TUI `main()` function never creates database tables. If they don't exist, every query crashes.
**Fix**: Add `models.Base.metadata.create_all(bind=engine)` before app.run().

### 3. CSS `#main-container` unused
**File**: `app/tui/styles.tcss:7-10`
No element with `id="main-container"` exists anywhere. Rule is dead code.
**Fix**: Remove `#main-container` block.
